Submit a task.
If queue is full:
    - self._reject_on_full=True  -&gt; Raises asyncio.QueueFull
    - self._reject_on_full=False -&gt; Blocks caller until slot opens

Note: Automatically starts the queue on first submission (lazy initialization).
