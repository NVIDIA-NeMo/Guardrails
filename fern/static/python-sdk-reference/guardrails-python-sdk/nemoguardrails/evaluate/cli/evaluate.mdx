Evaluate the performance of the fact-checking rails defined in a Guardrails application.

This command computes accuracy for fact-checking.
Negatives can be created synthetically by an LLM that acts as an adversary and modifies the answer to make it incorrect.

<Indent>

Evaluates the performance of the topical rails defined in a Guardrails application.
Computes accuracy for canonical form detection, next step generation, and next bot message generation.
Only a single Guardrails application can be specified in the config option.

**Parameters:**

<ParamField path="config" type="List[str]" default="typer.Option(default=[''], exists=True, help='Path to a directory containing configuration files of the Guardrails application for evaluation. Can also point to a single configuration file.')">
Path to a directory containing configuration files of the Guardrails application for evaluation.
Can also point to a single configuration file. Defaults to [""].
</ParamField>

<ParamField path="verbose" type="bool" default="typer.Option(default=False, help='If the chat should be verbose and output the prompts.')">
If the chat should be verbose and output the prompts. Defaults to False.
</ParamField>

<ParamField path="test_percentage" type="float" default="typer.Option(default=0.3, help='Percentage of the samples for an intent to be used as test set.')">
Percentage of the samples for an intent to be used as test set. Defaults to 0.3.
</ParamField>

<ParamField path="max_tests_intent" type="int" default="typer.Option(default=3, help='Maximum number of test samples per intent to be used when testing. If value is 0, no limit is used.')">
Maximum number of test samples per intent to be used when testing.
If value is 0, no limit is used. Defaults to 3.
</ParamField>

<ParamField path="max_samples_intent" type="int" default="typer.Option(default=0, help='Maximum number of samples per intent indexed in vector database. If value is 0, all samples are used.')">
Maximum number of samples per intent indexed in vector database.
If value is 0, all samples are used. Defaults to 0.
</ParamField>

<ParamField path="results_frequency" type="int" default="typer.Option(default=10, help='Print evaluation intermediate results using this step.')">
Print evaluation intermediate results using this step. Defaults to 10.
</ParamField>

<ParamField path="sim_threshold" type="float" default="typer.Option(default=0.0, help='Minimum similarity score to select the intent when exact match fails.')">
Minimum similarity score to select the intent when exact match fails. Defaults to 0.0.
</ParamField>

<ParamField path="random_seed" type="int" default="typer.Option(default=None, help='Random seed used by the evaluation.')">
Random seed used by the evaluation. Defaults to None.
</ParamField>

<ParamField path="output_dir" type="str" default="typer.Option(default=None, help='Output directory for predictions.')">
Output directory for predictions. Defaults to None.
</ParamField>


</Indent>
