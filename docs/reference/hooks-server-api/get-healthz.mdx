<Aside>

```bash title="Request"
curl http://localhost:8100/healthz
```

```json title="200"
{"status": "pass"}
```

</Aside>

```text
GET http://localhost:8100/healthz
```

Kubernetes-style alias for [`GET /v1/health`](/reference/hooks-server-api/get-health).
Returns the same shallow liveness response.

## Response

Returns `200` with the `application/health+json` media type.

<ParamField path="status" type="string" required={true}>
Always `pass`.
</ParamField>
