NeMo Guardrails Gateway provides guardrails enforcement for native model APIs.
Apply the NVIDIA NeMo Guardrails library's configurable checks between your
applications and model services while preserving supported provider formats and
keeping your existing inference infrastructure.

The gateway runs as an HTTP reverse proxy. Provider bindings select the content
to inspect, and Rails supplies the checks. It forwards accepted provider JSON and
server-sent event (SSE) bytes without rebuilding them from the validation models.
Your application or surrounding infrastructure owns access controls, model
routing, budgets, and retry policies.

<Note>

The gateway currently supports a limited single-text inspection profile. Review
[provider coverage](/run-guardrailed-inference/using-gateway/providers-and-streaming#coverage-of-the-shipped-profiles)
before connecting your application.

It uses `python -m nemoguardrails.server.experimental`. The [Guardrails API
server](/run-guardrailed-inference/using-fastapi-server) (`nemoguardrails server`)
and [hooks server](/run-guardrailed-inference/using-hooks-server) are separate
applications with different commands and configuration contracts.

</Note>

## How the Pieces Fit

The following components define routing, inspection, and resource ownership:

| Piece | Responsibility |
| --- | --- |
| Application configuration | Choose upstream instances, operation bindings, dialects, and Rails IDs. |
| Provider binding and capability profile | Describe which content the current integration and pipeline can handle. |
| Rails configuration | Choose checks for that content and their dependencies. |
| Guard contract | Make the bound inspection coverage reviewable as an export. |
| HTTP transport | Perform the outbound exchange, with optional application-specific network policy. |

Check [provider coverage](/run-guardrailed-inference/using-gateway/providers-and-streaming#coverage-of-the-shipped-profiles)
before connecting your application. The built-in bindings currently support a
single user text input and one assistant text target; additional content needs
matching binding and checking support.

Start with the [quickstart](/run-guardrailed-inference/using-gateway/quickstart)
for the library's `server` extra and installed examples. For exact declaration
details, follow the technical references linked from each guide.
