The NVIDIA NeMo Guardrails library includes the Guardrails hooks server (`nemoguardrails hooks-server`), which checks a coding agent's tool calls before the agent runs them.
The agent's own pre-tool hook sends each call to the hooks server, which applies a tool policy and tool-call rails to it and answers with allow or deny.

The hooks server is a separate process from the [Guardrails API server](/run-guardrailed-inference/using-fastapi-server) (`nemoguardrails server`).
It serves only the agent hook endpoints, and it never calls a model to generate a response.
