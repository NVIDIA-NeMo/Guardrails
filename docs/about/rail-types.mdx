The NVIDIA NeMo Guardrails library applies guardrails at multiple stages of an LLM interaction. A rail type identifies where a guardrail runs in the request lifecycle, such as before the LLM call, during retrieval, across a conversation, around tool or function execution, or after the model generates a response.

Use rail types to decide which part of your LLM application to protect. Input and output rails are the most common, and retrieval, dialog, and execution rails help when your application uses retrieved context, multi-turn flows, or external systems.

## How Rail Types Fit the Request Lifecycle

The following table summarizes where each rail type runs and which use cases it commonly supports.

| Stage            | Rail Type       | Common Use Cases                                                |
| ---------------- | --------------- | --------------------------------------------------------------- |
| **Before LLM**   | Input rails     | Content safety, jailbreak detection, topic control, PII masking |
| **RAG pipeline** | Retrieval rails | Document filtering, chunk validation                            |
| **Conversation** | Dialog rails    | Flow control, guided conversations                              |
| **Tool calls**   | Execution rails | Action input/output validation                                  |
| **After LLM**    | Output rails    | Response filtering, fact checking, sensitive data removal       |

Input rails apply guardrails before the LLM is called by validating and sanitizing user inputs. Retrieval rails filter and validate retrieved knowledge, such as documents and chunks, to ensure only trusted context is provided to the LLM. Dialog rails steer and constrain the multi-turn conversation by enforcing flow logic and policies across turns. Execution rails control and validate tool or function calls, their arguments, and results to safely interact with external systems. Output rails evaluate and post-process model responses by filtering, editing, or blocking unsafe or off-policy content before it reaches users.
