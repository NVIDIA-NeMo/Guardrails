<a id="colang-doc"></a>

Colang 2.0 is a beta version of the Colang language and runtime.
Use this guide to review what changed from Colang 1.0, migrate existing configurations, work through the getting started examples, and explore the language reference.

<Warning>

The Colang 1.0 and Colang 2.x runtimes are deprecated in 0.25.0 and are removed in 0.27.0 (January 2027).
The IORails engine will not support Colang 2.x, and it does not run Colang flows.
From 0.27.0, a configuration that uses Colang 2.x or contains hand-written Colang flows fails to load.
For the steps, refer to [Migrating to 0.25](/reference/0-25#colang-configurations).

</Warning>
