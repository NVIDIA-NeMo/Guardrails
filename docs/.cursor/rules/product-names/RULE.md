# Overarching Convention

## Referring to Product Names

Instead of using "NemoGuard", which is the old name, refer to the products by their full names: Nemotron Content Safety, Nemotron Jailbreak Detect, and Nemotron Topic Control.

- NemoGuard Content Safety -> Nemotron Content Safety
- NemoGuard Jailbreak Detection -> Nemotron Jailbreak Detect
- NemoGuard Topic Control -> Nemotron Topic Control

When referring collectively to these NIM microservices, use Nemotron Guard. For example, when it mentions "NemoGuard models", replace it with "Nemotron Safety models".
